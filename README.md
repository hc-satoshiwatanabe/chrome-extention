# kintone 経路マップ (kintone Path Map)

kintone(cybozu.com / kintone.com)内のページ遷移(アプリ内のSPA遷移も含む)を記録し、経路マップ(マインドマップ)として可視化するChrome/Edge拡張機能です。サイボウズ株式会社の公式製品ではない、非公式の個人開発ツールです。

- リポジトリ: https://github.com/hc-satoshiwatanabe/chrome-extention (旧名称"Link Dialog for kintone"から改名。URLは変更していません)
- プライバシーポリシー: [PRIVACY.md](PRIVACY.md)（公開URL: https://github.com/hc-satoshiwatanabe/chrome-extention/blob/main/PRIVACY.md ）
- サードパーティライセンス: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)

> v2.0.0で、リンクをダイアログ(iframe)表示する機能は廃止しました。現在は経路の記録・可視化に特化しています。それに伴い、拡張機能名も「Link Dialog for kintone」から「kintone 経路マップ」に変更しました。

## インストール(Chrome / Edge共通・開発者モード)

1. `chrome://extensions`(Edgeは`edge://extensions`)を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択する
4. kintoneのページを開き直す(既に開いているタブはリロードが必要)

## 使い方

- kintone(今開いているテナントと同じオリジン)のページを閲覧すると、ページ遷移のたびに自動的に経路として記録されます。リンクをクリックする必要はなく、通常のブラウジング(戻る/進む、アドレスバー入力、ブックマークなど)がそのまま記録対象です
- kintoneはアプリ内の遷移(一覧→レコード→関連レコードなど)の多くをSPA的に(ページを再読み込みせず)行うため、`history.pushState`/`hashchange`を監視して検知しています
- リンクを`Ctrl`/`Cmd`/`Shift`/`Alt`を押しながらクリックしたり、`target="_blank"`のリンク、中クリックなどで**新しいタブ**を開いた場合も、そのタブでの経路が元の経路につながって記録されます
- kintoneのカスタマイズ(JS)が`window.open()`を呼び出して新しいタブを開く場合(ルックアップ項目からの関連レコードリンクなど、`<a>`タグを介さないケース)も検知して経路をつなげます
- 別アプリへの完全なページ遷移(SPAではなく実際のページ再読み込み)でも、同じタブ内であれば経路はつながります(`sessionStorage`でタブ内の現在地を保持しているため)
- 拡張機能アイコンの「経路マップを見る」から、記録された経路をツリー図(マインドマップ)で確認できます。描画には[Cytoscape.js](https://js.cytoscape.org/)を使用しており、マウスホイールでズーム、ドラッグでパン(視点移動)ができます。「履歴をクリア」でいつでも消去できます
- ノードをクリックすると、画面右側にドロワー(詳細パネル)が開き、種別(一覧/レコード)・レコード番号・記録日時・URLなどを確認できます。ドロワー内の「新しいタブで開く」ボタンでそのページを実際に開けます(同じURLのタブがすでに開いていれば、新規タブを作らずそのタブをアクティブにします)。ドロワーは×ボタン・外側クリック・`Esc`キーで閉じます
- ドロワー内の「このノードを削除」から、そのノード1件だけを個別に削除できます(確認ダイアログあり)。削除したノードに子があった場合は、その子は削除したノードの親に付け替えられ、経路のつながりは維持されます
- 経路マップのノードには、URLの代わりにアプリ名(kintoneのREST API `app.json` から取得)が表示されます(一覧は「アプリ名 - 一覧」)。取得できない場合はURLのまま表示されます
- レコード詳細のノードは、アプリの「レコードのタイトルフィールド」設定(`app/settings.json`の`titleField`)の値を取得して表示します。手動設定されていない場合は、フォームの表示順(`app/form/layout.json`)で最初に現れる文字列1行フィールド**と、その次のフィールド**の値を組み合わせて表示します(例:「取引先コード 取引先名」のように、コードだけでは分かりにくい場合の補完を狙っています)。いずれも取得できない場合は「アプリ名 - レコード#番号」にフォールバックします
- 経路マップは5秒ごとに自動的に再読み込みされ、別タブでの閲覧状況をほぼリアルタイムに反映します
- 拡張機能アイコンのチェックボックスで、経路の記録自体をON/OFFできます(デフォルトON)
- 同じページに複数回たどり着いた場合、重複したノードは作らず**同じノードを再利用**します。同一性の判定は完全なURL一致ではなく「アプリID・種別(一覧/レコード)・レコードID」単位で行うため、`?view=`などの付随パラメータが違っても同じページとして扱われます。そのノードから複数の経路が分岐している形で表示され、最初にそのページへ辿り着いた経路の親子関係が優先されます(後から別経路で再訪しても親は変わりません)

### 経路マップの制約

- URLに`/space`または`/portal`を含むページ(スペース・ポータル画面)は記録対象外です
- 記録はURLの変化を検知する仕組みのため、kintoneが内部的にURLだけ変えるが実質同じ画面、といったケースを誤って記録することがあります
- 新しいタブへの経路の引き継ぎは、URLと数秒程度の有効期限による突き合わせのため、同じURLへ短時間に複数回リンクを開いた場合など、まれに親子関係を取り違えることがあります
- `window.open()`の横取りは、そのページのスクリプトが読み込まれる前に(まれに)ネイティブの`window.open`への参照を保持していた場合、検知できないことがあります
- 記録は端末のブラウザ内(`chrome.storage.local`)にのみ保存され、外部には送信されません。直近500件を超えると古いものから自動的に削除されます

## 対象ドメインの変更

`manifest.json`の`content_scripts[0].matches`で対象ドメインを指定しています。デフォルトは以下です。

```json
"matches": [
  "https://*.cybozu.com/*",
  "https://*.kintone.com/*"
]
```

独自ドメイン(カスタムドメイン)でkintoneを利用している場合は、このパターンにそのドメインを追加してください。変更後は`chrome://extensions`の当該拡張機能で「再読み込み」を行ってください。

## 既知の制約

- kintoneの画面リニューアル等でDOM構造・URL構造が変わった場合、動作しなくなる可能性があります。
